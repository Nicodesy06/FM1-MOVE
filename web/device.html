Install FM1 Move, then manage the FM-1 from here.
Connect the FM-1 with a USB data cable straight to the computer and use Chrome or Edge on a desktop. Or try every page on the virtual FM1: the FM1 Move firmware itself, compiled to WebAssembly, with its flash kept in this browser.

FM1 Move EXPERIMENTAL

Eight tracks of any kind, the Groove Engine, the new screens, FM1M projects, and this device page.

Never run on an FM-1 yet. This build is compiled with the real JieLi compiler and tested only in simulation (host tests and the virtual FM1). Timing, audio load and the display bus of a real FM-1 have not been tried. Install it only on an FM-1 you are ready to recover (see Rescue below). Save a SLOOP backup first if you have one.

SLOOP STABLE

The firmware FM1 Move is built on, by Leo Kuroshita (Hügelton Instruments): four tracks, 12 engines, its own web editor. Install it to go back from FM1 Move, or to use a stable firmware.

Sample slots

    

    
About 3.7 s of sound each (80 KiB, IMA ADPCM at 22 kHz). A drum track plays one as a kit (KIT USR1–USR3), a synth track with
      the SAMPLE or GRAIN engine as an instrument. FM1 Move has three slots: SLOOP's fourth (USR4) is where FM1 Move keeps its projects.

FM6 patch bank

      

    

    
The FM6 engine (six operators, DX7 patches) plays the 8 factory patches F1–F8 and the 27 of the bank B1–B27 (its PTCH parameter).
      DX7 cartridges (32 voices) and single voices load.

    

      

      

       The ticked voices go to B1, B2… in order; the other bank slots stay.

Projects

    
The working project is what plays now (kept by the autosave). Four slots keep projects; a project file (.fm1m.json) moves one between
      FM-1s, or into the virtual FM1. Stop the FM-1 (PLAY) before you load, save or import.

Back up everything

      
One file with all the FM-1 keeps: the working project, the four projects, the user presets, the FM6 bank, the SYN kits, the
        three sample slots and the settings.

      
    

    

      
Restore

      
Puts a backup back, object by object: each is checked whole by the FM-1 before it is written, so a cut-off restore never
        leaves half a project. It replaces what is on the FM-1. FM1 Move backups only (SLOOP's projects are another format).
